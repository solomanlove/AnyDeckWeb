Android、HarmonyOS 与 iOS 的版本编号不能直接横向等同。这里按各平台官方口径整理开发时真正需要核对的 API 与工具链关系。

Android

系统版本 ↔ API 级别

每个 Android 平台版本对应一个整数 API 级别。应用还需分别检查 minSdk、targetSdk 与 compileSdk。

HarmonyOS

系统版本 ↔ API 版本

HarmonyOS NEXT 使用 API 版本、targetSdkVersion 与 compatibleSdkVersion。同一大版本可能包含多个 API 版本，不能按 Android API 级别推断。

iOS / iPadOS

系统版本 ↔ Xcode / SDK

iOS 没有 Android 式 API 级别。开发兼容性由 Xcode 自带 SDK、项目的最低部署版本，以及 @available 版本守卫共同决定。

Apple 官方工具链矩阵 ↗

不要混淆三个概念：当前设备系统版本 ≠ 编译使用的 SDK ≠ 应用可安装的最低部署版本。
