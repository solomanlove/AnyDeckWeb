快速开始

  1. 在电脑安装 Android SDK 平台工具，并确认 adb version 可正常输出。
  2. 在 Android 设备开启“开发者选项”与“USB 调试”。
  3. 使用数据线连接设备，在手机弹窗中选择允许调试。
  4. 打开 AnyDeck，在设备列表选择目标设备，即可进入概览、控制、应用、文件或日志工作区。

macOS 可使用 brew install android-platform-tools 安装 ADB；Windows 可使用 Chocolatey 或 Scoop 安装 ADB。内嵌投屏无需另外安装 scrcpy，仅“电脑本地录制”等外部录制模式按需安装该 CLI。

通过 USB 连接设备

  1. Android 开启“开发者选项”与“USB 调试”；HarmonyOS 按系统版本开启 ADB 或 HDC 调试。
  2. iPhone / iPad 解锁后确认“信任此电脑”；需要安装开发包或自动化控制时再开启“开发者模式”。
  3. 使用支持数据传输的线缆连接电脑，并在手机上确认调试或配对授权。
  4. 返回 AnyDeck 刷新设备列表，确认状态为已连接。

不同厂商的菜单位置与额外开关请查看 USB 调试与设备信任完整指南 →。Android 显示 unauthorized 时请解锁手机并重新确认 RSA 授权；显示 offline 时可重新插拔 USB 后刷新。

通过 Wi‑Fi 连接

Android 11+ 推荐使用“无线调试”的二维码或配对码。电脑与手机需要在同一可互访局域网。

  1. 先在手机打开“无线调试”。
  2. 在 AnyDeck 设备管理中选择配对方式，录入 IP、配对端口与配对码，或使用二维码流程。
  3. 配对成功后选择调试端口建立连接。

连接超时通常与 VPN、系统防火墙、路由器接入点隔离或 IP/端口变化有关。

配置 HTTP 正向代理与端口转发

三种能力解决的问题不同：设备 HTTP 正向代理把 Android 的 HTTP 流量交给电脑上的代理服务；正向端口映射让电脑访问设备端 TCP 服务；反向端口映射让 Android 应用访问电脑上的本地开发服务。

  1. Android HTTP 代理：填写电脑在局域网中的 IPv4 地址与代理端口，例如 192.168.1.8:8888，应用后可回读当前值，也可一键清除恢复直连。
  2. 正向映射：填写电脑端与设备端 TCP 端口，流向为“电脑 localhost → 设备 localhost”。Android 与 HarmonyOS 均支持手动创建、查看和删除。
  3. 反向映射：填写设备端与电脑端 TCP 端口，流向为“设备 localhost → 电脑 localhost”。当前支持 Android，可保存预设并在设备连接后自动应用。
adb forward tcp:9222 tcp:9222
hdc fport tcp:9222 tcp:9222
adb reverse tcp:8081 tcp:8081

能力边界：端口映射仅支持 TCP，端口范围为 1–65535。设备 HTTP 代理当前仅支持 Android 全局代理，不等同于 VPN，也不支持身份认证、SOCKS、PAC 或按应用分流；HarmonyOS 暂无对应的 HDC 代理配置。

打开投屏并控制设备

从设备行或工作区顶部打开投屏窗口。投屏窗口支持鼠标触控、键盘输入、返回、主页、电源、音量、旋转、截图与独立窗口缩放。

  • 鼠标左键用于点击与拖动。
  • 鼠标右键默认映射为 Android 返回键。
  • 鼠标中键默认映射为 Android 主页键。
  • 关闭窗口或断开设备时，AnyDeck 会结束对应会话并回收端口。

演示或讲解画面时，可切换到投屏白板，直接在电脑端标记重点。

在投屏画面上使用白板

白板适合文档演示和界面讲解。Android、HarmonyOS，以及 macOS 版的 iOS USB 与 AirPlay 投屏窗口都可在电脑端画面上显示笔迹。

  1. 打开投屏窗口，点击右侧工具栏、截图按钮附近的画笔 icon，开启白板模式。
  2. 将鼠标移到手机画面上，按住左键拖动即可划线或圈出重点；单击也能留下一个圆点。
  3. 使用画笔下方的三个按钮：第一个选择红、黄、绿、蓝、黑、白六种颜色；第二个撤销上一笔；第三个清空当前窗口的全部笔迹。
  4. 再次点击画笔 icon 退出白板模式，已有标记仍会显示；此时可继续用鼠标和键盘控制手机。需要继续画时，再次开启白板。

标注边界：白板开启时，画面上的点击、拖动、右键、滚轮与键盘输入不会发送给手机。笔迹只保存在当前投屏窗口，不会写入手机屏幕；现有设备截图和录屏不会包含电脑端笔迹。关闭投屏窗口或切换视频方向后，笔迹会清除。每个窗口最多保留 200 笔。

编辑截图：标注与遮盖

Android、HarmonyOS 与 iOS 的截图均可在 AnyDeck 内直接编辑，适合标记界面问题、圈出操作位置，或遮盖截图中的信息。

进入编辑并保存

  1. 选择目标设备，打开“截图录屏”并获取一张截图。
  2. 点击右上角、布局分析开关左侧的铅笔按钮“编辑图片”。没有截图、正在加载或录屏时，入口不可用。
  3. 选择工具、颜色与线宽，按住鼠标左键拖动绘制。需要移动图片时，切换到“拖动画布”；底栏可放大、缩小、切换 1:1 或恢复适应窗口。
  4. 点击“完成”返回截图页，再使用“保存”或“复制”导出编辑后的 PNG。保存图片时也会同步复制到系统剪贴板。

工具怎么用

  • 矩形、圆形：拖出空心矩形或椭圆，标记重点区域；反向拖动也可绘制。
  • 画笔：按住鼠标自由绘制线条，单击可留下圆点。
  • 马赛克：沿鼠标笔迹像素化局部画面，可通过线宽调整涂抹范围。
  • 不透明遮盖：拖出实色矩形，完全盖住区域。账号、证件号码等需要彻底隐藏的内容建议使用此工具；马赛克仍可能保留可辨认的形状。
  • 颜色与线宽：提供红、黄、绿、蓝、黑、白六色；线宽按原图像素计算，缩放预览不会改变导出的实际宽度。
  • 撤销、重做、清空：一次落笔对应一次撤销。“清空本次标注”会移除本次会话的所有标注及撤销记录。每次会话最多 200 笔，达到上限后可撤销或清空再继续。

完成、取消与重新截图

  • “完成”将标注合成到当前图片。重新进入编辑时，以已完成的图片作为底图，上次会话的撤销记录不再保留。
  • 点击“取消”且已有标注时，可选择“继续编辑”或“放弃编辑”；放弃后恢复进入本次编辑前的画面。
  • 进入编辑会暂停连续截图；完成或取消后仍保持暂停，需要时手动重新开启。刷新截图成功后，当前编辑结果会被新截图替换，请先保存或复制需要保留的图片。
  • 编辑期间暂时收起布局分析侧栏，并停用刷新、录屏与布局分析切换。完成或取消后恢复原工作区模式。
  • 切换普通工具 Tab 会保留草稿；切换设备或离开设备工作区会放弃尚未完成的标注。

导出说明：PNG 保留原图分辨率与方向。旋转仅用于预览，不会改变导出方向；工具栏、布局分析高亮和缩放比例不会写入图片。

使用 iOS AirPlay 无线投屏

macOS 版 AnyDeck 可作为 AirPlay 接收端，接收 iPhone 或 iPad 的无线屏幕镜像，并在独立窗口播放画面与设备音频。

  1. 让 iPhone / iPad 与 Mac 连接同一个可互访的 Wi‑Fi；关闭可能阻断局域网发现的 VPN 或接入点隔离。
  2. 在 AnyDeck 中启动 AirPlay 接收服务，并确认页面显示接收名称 AnyDeck-AirPlay。
  3. 在 iPhone / iPad 打开“控制中心”，点击“屏幕镜像”，选择 AnyDeck-AirPlay。
  4. 等待 AnyDeck 打开投屏窗口。结束时回到“屏幕镜像”，点击“停止镜像”。

能力边界：当前 AirPlay 接收服务是仅支持 macOS 的实验性能力，不提供从 Mac 反向控制 iPhone / iPad。HLS、HEVC 与 DRM 保护内容不属于当前兼容范围；连接质量还会受到 Wi‑Fi、路由器隔离和系统版本影响。

将手机视频投到电脑播放

Android 与 HarmonyOS 手机可通过 DLNA，将抖音、哔哩哔哩、小红书、爱奇艺等 App 中支持投屏的视频发送到 AnyDeck 播放窗口。

  1. 让手机与电脑连接同一个可互访的局域网。
  2. 在 AnyDeck 中开启 DLNA 视频接收，并确认电脑端显示接收名称。
  3. 在手机视频 App 的播放页点击“投屏”或 TV 图标。
  4. 在设备列表选择 AnyDeck，电脑端会自动打开或复用播放窗口。

兼容性说明：投屏能力取决于 App 版本、账号、地区、片源协议与 DRM 限制。部分内容可能不提供投屏入口；App 内弹幕不会随视频传输。

统一管理本地模拟器

AnyDeck 会扫描本机已有的 Android AVD、DevEco Emulator 与 Xcode Simulator，在同一个列表中展示平台、系统版本、分辨率、SDK、ABI、内存、存储与运行状态。

  1. 从左侧导航进入“模拟器管理”，选择 Android、HarmonyOS 或 iOS 平台。
  2. 使用名称或规格搜索目标模拟器，并查看配置详情。
  3. 选择模拟器后执行启动、停止、冷启动、刷新或打开配置目录。
  4. 启动失败时点击错误状态，查看并复制有界诊断日志。

边界说明：AnyDeck 管理已由 Android Studio、DevEco Studio 或 Xcode 创建的模拟器，不自动下载系统镜像，也不代替对应开发工具创建新设备。

分析 APK、APKS、AAB、XAPK 与已安装应用

macOS 可通过“访达”使用 AnyDeck 打开本地 APK、APKS、AAB 或 XAPK。离线分析无需连接手机，也不需要额外安装 Android SDK 或 Java；查看已安装应用时，在设备应用列表双击目标应用进入详情。

  1. 右键点击本地安装包，选择“打开方式 → AnyDeck”，进入独立详情窗口。
  2. 在概要区确认文件格式、包名、版本、最低 SDK、目标 SDK 与 ABI。
  3. 切换分包、模块、组件、权限、元数据、DEX、签名证书或原生库标签页，使用搜索与复制定位信息。
  4. 普通 APK 可选择已授权的在线 Android 设备安装；APKS、AAB、XAPK 当前仅支持分析，不提供安装操作。
  5. 已安装 Android 应用可继续执行启动、强停、授权或撤销等设备操作；HarmonyOS 使用独立 HDC 分析链路。
  • APKS：查看内含 APK 清单，汇总同包名、同版本的组件与文件，并保留来源。不同设备变体不代表会同时安装全部内容。
  • XAPK：在分包分析之外，查看 OBB 扩展文件与容器元数据；不会自动推送扩展文件。
  • AAB：查看基础模块、功能模块、资源包、模块内 DEX 和原生库，以及 JAR 上传证书。AAB 需要生成适合设备的 APK 后才能安装。

若要默认用 AnyDeck 打开某类安装包，可在“访达 → 显示简介 → 打开方式”中选择 AnyDeck 并点击“全部更改”；不同扩展名需要分别设置。

证书与权限：本地安装包的权限表示清单文件声明，证书读取不等同于完整性验签；AAB 的上传证书可能与商店分发 APK 的签名不同。设备中应用的授权状态以当前用户和系统回读为准。

使用 AnyDeck 运行控制台

运行控制台用于排查 AnyDeck 桌面应用自身的问题。它会实时汇总主窗口与投屏等子窗口的运行日志、异常堆栈，以及 ADB / HDC 命令失败，无需连接手机也可打开。

  1. 打开 AnyDeck 的“控制台”独立窗口，查看当前会话的实时日志。
  2. 使用关键词搜索窗口来源、命令或错误内容；打开“仅关键日志”可只看警告、错误与严重错误。
  3. 按需隐藏设备心跳日志，并开启自动滚动跟随最新记录。
  4. 复现问题后复制相关记录，或使用“导出”保存包含保留历史会话的 .log 诊断文件。
  5. 分享日志前检查其中可能存在的设备标识、本地路径或业务数据。

日志边界：清空控制台只会清理当前显示，不会删除磁盘中的诊断记录。控制台不等同于手机系统日志，也不会采集未转发到 Dart 的原生标准错误或系统原生崩溃报告。

连接 AI 客户端与 AnyDeck MCP 服务

AnyDeck 通过 HTTP SSE 提供 22 项 MCP 工具，覆盖设备发现、截图与界面操作、应用生命周期、系统日志、崩溃、文件传输和受控命令行。不同平台实际可用工具以当前设备能力为准。

  1. 进入 AnyDeck 的“AI MCP”页面，确认监听地址与端口后启动服务。
  2. 按需启用工具；不需要的写入、卸载、清数据或命令行工具保持关闭。
  3. 在 Cursor、Claude Desktop、Cline、Windsurf 或其他 MCP 客户端中添加 SSE 地址。
  4. 连接成功后先调用 list_devices，再让 AI 针对明确的设备执行截图、分析或诊断操作。
  5. 在 AnyDeck 审计日志中检查请求参数、耗时、结果和错误。
{
  "mcpServers": {
    "anydeck": {
      "url": "http://127.0.0.1:8765/sse"
    }
  }
}

安全说明：默认仅监听本机地址，并提供工具级开关、高危命令黑名单和调用审计。MCP 客户端获得的是实际设备操作能力，只连接可信客户端，并在执行卸载、清数据、文件写入或命令行操作前核对目标设备与参数。

管理应用与文件

应用工作区支持检索、APK 安装、启动、卸载、清除数据、冻结/解冻与导出。文件工作区用于浏览设备存储，并支持上传、下载与删除。

  • 安装 APK：将文件拖入设备窗口或使用安装入口。
  • 批量操作：先进入多选状态，再选择目标应用执行动作。
  • 文件传输：确认设备剩余空间与目标目录权限；系统保护目录通常需要 Root。

使用系统日志、终端与布局分析

系统日志适合观察实时系统与应用日志；终端提供交互式 ADB 命令行；布局分析会读取当前界面的 XML 层级，并与截图区域关联。

  1. 先确认目标设备，避免日志与命令发往其他连接。
  2. 系统日志使用包名、标签或关键词缩小范围。
  3. 需要复现崩溃时，先清空无关日志，再执行复现步骤。
  4. 布局抓取为空时，确认页面未使用受保护画面，并尝试刷新。

常见连接问题

  • 找不到 ADB：将平台工具加入 PATH，或从 Android SDK 目录执行。
  • 设备未出现：更换支持数据传输的线缆与 USB 端口，随后运行 adb devices 交叉检查。
  • 无线连接被拒绝：确认配对端口与连接端口没有混用，并检查手机 IP 是否变化。
  • 投屏启动失败：确认只有一个有效设备目标、USB/Wi‑Fi 链路稳定，并查看 AnyDeck 本地诊断日志。
  • 仍无法解决：导出诊断信息后，在 GitHub 问题页面描述系统版本、设备型号、连接方式与复现步骤。
