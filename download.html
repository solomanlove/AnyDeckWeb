从源码构建

从源码开始。

需要 Flutter SDK 与目标平台桌面开发环境。下面命令会拉取主仓库并启动 macOS 开发版本。

git clone https://github.com/solomanlove/AnyDeck.git
cd AnyDeck
flutter pub get
flutter run -d macos
下载源码 ZIP打开 GitHub 仓库 ↗

环境要求

运行前准备。

基础 Android 调试依赖 ADB；其他平台或扩展能力按需准备对应工具链。

Android / ADB

安装 Android SDK platform-tools，并确保终端可执行 adb devices。

屏幕投射

项目内包含投屏服务组件；本地构建时按仓库脚本准备 Rust 原生桥接。

HarmonyOS / HDC

管理 HarmonyOS NEXT 设备时，需要 DevEco Studio 提供的 HDC 工具链。

iOS / go-ios

iOS 连接与调试需要 go-ios；部分投屏与 Web Inspector 能力当前依赖 macOS。

第一次使用？

从环境检查、USB 授权到无线连接，帮助中心给出完整路径。
