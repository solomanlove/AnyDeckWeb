macOS 安装指南

安装与首次打开。

从官方 GitHub Release 下载安装包，按以下步骤完成安装。无需安装 Flutter 或 Rust 开发环境。

  1. 安装到“应用程序”。打开下载的 DMG，将 AnyDeck 拖到 Applications 文件夹；如果使用 ZIP，先解压，再将 AnyDeck.app 拖到“应用程序”。

  2. 尝试打开 AnyDeck。在“应用程序”中双击打开。如果提示无法验证开发者或 Apple 无法检查恶意软件，先关闭提示。

  3. 按需允许首次打开。确认安装包来自上方官方 Release 后，进入“系统设置 → 隐私与安全性”，找到 AnyDeck 的拦截提示，点击“仍要打开”，再按系统提示确认。后续通常可以正常打开。

此 ad-hoc 版本暂不支持激活 macOS 系统虚拟摄像头。连接手机仍需下方对应的设备工具及手机调试授权。

从源码构建

从源码开始。

需要 Flutter SDK 与目标平台桌面开发环境。下面命令会拉取主仓库并启动 macOS 开发版本。

git clone https://github.com/solomanlove/AnyDeck.git
cd AnyDeck
flutter pub get
flutter run -d macos
下载源码 ZIP打开 GitHub 仓库 ↗

环境要求

运行前准备。

基础 Android 调试依赖 ADB；其他平台或扩展能力按需准备对应工具链。

Android / ADB

安装 Android SDK platform-tools，并确保终端可执行 adb devices。

屏幕投射

发布安装包已包含投屏服务端和 Rust 原生引擎；手机连接仍需对应的 ADB / HDC 工具及调试授权。

HarmonyOS / HDC

管理 HarmonyOS NEXT 设备时，需要 DevEco Studio 提供的 HDC 工具链。

iOS / go-ios

iOS 连接与调试需要 go-ios；部分投屏与 Web Inspector 能力当前依赖 macOS。

第一次使用？

从环境检查、USB 授权到无线连接，帮助中心给出完整路径。
