USB 连接指南

让手机准备好，
再交给 AnyDeck。

不同品牌的入口名称不完全相同，但目标一致：允许电脑与设备建立可信的调试连接。按系统和厂商选择下面的路径。

Android 厂商HarmonyOSiPhone / iPad验证连接连接故障
ADB

Android

开启“开发者选项”和“USB 调试”，再确认 RSA 调试授权。

HDC

HarmonyOS

HarmonyOS 5+ 使用 HDC；较早兼容版本也可能通过 ADB 连接。

iOS

iPhone / iPad

iOS 没有“USB 调试”开关；先信任电脑，需要开发能力时再开启“开发者模式”。

Android / ADB

按手机厂商开启 USB 调试

菜单名称会随系统版本变化。找不到入口时，可在系统设置顶部搜索“版本号”“开发者选项”或“USB 调试”。

Google / 摩托罗拉 / 联想 / 华硕 / Nothing

原生或接近原生 Android

  1. 进入“设置 → 关于手机”，连续点击“版本号”7 次。
  2. 返回“设置 → 系统 → 开发者选项”。
  3. 打开“USB 调试”，连接电脑后允许 RSA 授权。
关于手机 → 版本号 × 7
系统 → 开发者选项 → USB 调试
小米 / Redmi / POCO

小米 / Redmi：MIUI 与 HyperOS

  1. 进入“设置 → 关于手机 / 我的设备 → 详细信息与规格 / 全部参数”。
  2. 连续点击“系统版本 / HyperOS 版本 / MIUI 版本”7 次。
  3. 进入“更多设置 / 附加设置 → 开发者选项”，打开“USB 调试”。
  4. 手机已识别但无法控制时，再检查“USB 调试（安全设置）”；部分版本要求登录小米账号。
关于手机 → 系统 / MIUI 版本 × 7
更多设置 → 开发者选项 → USB 调试
OPPO / 一加 / realme

ColorOS / OxygenOS / realme UI

  1. 进入“设置 → 关于本机 / 关于设备 → 版本”。
  2. 连续点击“版本号”7 次并验证锁屏密码。
  3. ColorOS 14.1+ 通常进入“系统与更新 → 开发者选项”；较早版本位于“系统设置 / 其他设置”。
  4. 打开“USB 调试”并确认。
关于设备 → 版本 → 版本号 × 7
系统与更新 / 系统设置 → 开发者选项
vivo / iQOO

OriginOS / Funtouch OS

  1. 进入“设置 → 系统管理 → 关于手机 → 版本信息”。
  2. 连续点击“软件版本号”7 次。
  3. 返回“系统管理 → 开发者选项”。
  4. 打开“USB 调试”，连接时选择允许。
系统管理 → 关于手机 → 软件版本号 × 7
系统管理 → 开发者选项 → USB 调试
三星 Galaxy

三星 One UI

  1. 进入“设置 → 关于手机 → 软件信息”。
  2. 连续点击“编译编号”7 次并输入锁屏密码。
  3. 返回设置首页，进入底部的“开发者选项”。
  4. 打开“USB 调试”，连接电脑后确认授权。
关于手机 → 软件信息 → 编译编号 × 7
设置 → 开发者选项 → USB 调试
荣耀

荣耀 MagicOS

  1. 进入“设置 → 关于手机”。
  2. 连续点击“版本号”7 次。
  3. 返回“设置 → 系统和更新 → 开发人员选项”。
  4. 打开“USB 调试”并接受电脑的 RSA 指纹。
关于手机 → 版本号 × 7
系统和更新 → 开发人员选项 → USB 调试
华为 EMUI

华为 EMUI

  1. 进入“设置 → 关于手机”。
  2. 连续点击“版本号”7 次并输入锁屏密码。
  3. 进入“设置 → 系统和更新 → 开发人员选项”。
  4. 打开“USB 调试”；仅充电模式无法发现时，同时打开“仅充电模式下允许 ADB 调试”。
关于手机 → 版本号 × 7
系统和更新 → 开发人员选项 → USB 调试
魅族 / 其他 Android

魅族 Flyme 与其他品牌

  1. 优先在“设置 → 关于手机”连续点击“版本号 / 软件版本号”7 次。
  2. 回到“系统 / 辅助功能 / 更多设置”查找“开发者选项”。
  3. 打开“USB 调试”；如菜单与上述不同，直接使用设置搜索。
  4. 不需要开启“OEM 解锁”，也不需要解锁启动引导程序。
设置搜索 → 开发者选项 / USB 调试

连接时最后一步：保持手机解锁，USB 用途可选“文件传输 / Android Auto”，在“是否允许 USB 调试”弹窗核对电脑 RSA 指纹后选择允许。只在自己的电脑上勾选“始终允许”。

HarmonyOS / HDC

鸿蒙设备开启 USB 调试

HarmonyOS 4.x 及以下与 HarmonyOS 5+ 的入口和连接协议不同，请先在“设置 → 关于手机”确认系统版本。

HarmonyOS 4.x 及以下

兼容系统版本

  1. 进入“设置”，搜索并打开“软件版本”。
  2. 连续点击“HarmonyOS 版本”7 次，直到提示已处于开发者模式。
  3. 进入“设置 → 系统和更新 → 开发人员选项”。
  4. 打开“USB 调试”；若使用仅充电模式，再打开“仅充电模式下允许 ADB 调试”。
  5. 连接电脑并确认 RSA 调试授权。
HarmonyOS 版本 × 7
系统和更新 → 开发人员选项 → USB 调试
HarmonyOS 5+

原生鸿蒙系统

  1. 进入“设置 → 设备名称 / 设备型号”，找到“软件版本号”。
  2. 连续点击“软件版本号”7 次，按提示确认重启并开启开发者选项。
  3. 重启后进入“设置 → 系统 → 开发者选项”。
  4. 打开“USB 调试”，连接电脑后确认调试授权。
  5. AnyDeck 将通过 HDC 发现设备，不要用 adb devices 判断 HDC 连接。
设备型号 → 软件版本号 × 7 → 重启
系统 → 开发者选项 → USB 调试

注意：工作资料设备、儿童模式、健康使用手机、隐私空间或组织管理策略可能隐藏或禁用开发者选项。请先切回主空间，并联系设备管理员确认策略。

iOS / USB 配对

iPhone 与 iPad 信任电脑

iOS 没有名为“USB 调试”的开关。普通识别只需完成 USB 配对；安装本地开发包、Xcode 调试或自动化控制时才需要“开发者模式”。

所有 iPhone / iPad

完成 USB 配对

  1. 使用支持数据传输的 USB‑C 或 Lightning 线连接电脑并解锁设备。
  2. Mac 弹出“允许配件连接”时选择“允许”。
  3. iPhone / iPad 出现“要信任此电脑吗？”时选择“信任”，并输入设备密码。
  4. 返回 AnyDeck 刷新设备列表。
连接并解锁 → 允许配件 → 信任此电脑
iOS / iPadOS 16+

按需开启开发者模式

  1. 先通过 Xcode 的设备管理窗口发起设备配对；否则“开发者模式”入口可能不会出现。
  2. 进入“设置 → 隐私与安全性 → 开发者模式”。
  3. 打开开关并按提示重启。
  4. 设备重启后解锁，确认“打开开发者模式”并输入密码。
  5. 重新连接 AnyDeck，继续 WDA 或开发调试流程。
隐私与安全性 → 开发者模式 → 重启 → 确认

安全边界：“信任此电脑”允许电脑访问设备信息；“开发者模式”允许运行本地开发签名应用。只对可信电脑授权，使用结束后可在“设置 → 通用 → 传输或还原 → 还原 → 还原位置与隐私”撤销已信任电脑。

连接验证

确认设备已经连通

先用对应平台的命令行工具判断底层连接，再回到 AnyDeck 刷新。这样能快速区分系统授权问题与应用界面问题。

Android / HarmonyOS

Android 应显示 device；HarmonyOS 5+ 应在 HDC 列表中出现目标。

adb devices
hdc list targets
  • unauthorized：解锁手机并接受授权。
  • offline：重新插拔数据线并刷新。
  • 空列表：检查线缆、USB 口、系统开关与驱动。

iPhone / iPad

在安装 Xcode 的 Mac 上，可用设备控制命令查看已配对设备。

xcrun devicectl list devices
  • 未出现：解锁设备并重新确认“信任此电脑”。
  • 开发者模式缺失：先在 Xcode 的设备管理窗口发起配对。
  • Windows 需要“Apple 设备”应用与对应驱动；AnyDeck 的 iOS 开发能力以 macOS 为主。

故障排查

连接后仍看不到设备？

从物理链路到系统授权逐层排查，通常不需要重装 AnyDeck。

先检查这 5 项

  1. 线缆必须支持数据传输，不是仅充电线。
  2. 保持设备解锁，重新插拔并观察系统弹窗。
  3. 换用电脑直连 USB 口，暂时移除扩展坞。
  4. Android 将 USB 用途切换为“文件传输”。
  5. 关闭占用设备的其他手机助手、IDE 或调试工具后刷新。

重新触发授权

  • Android：开发者选项中“撤销 USB 调试授权”，重连后再次允许。
  • HarmonyOS：关闭再打开 USB 调试，确认当前是主空间且未受组织策略限制。
  • iOS：还原“位置与隐私”后重连，再次选择“信任”。
  • 仍失败：记录设备型号、系统版本、命令行输出和 AnyDeck 诊断日志后提交问题。
